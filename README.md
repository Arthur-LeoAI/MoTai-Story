# 墨台小说创作平台

墨台是一款本地优先的中文小说创作工具。新版工作台围绕“和 AI 讨论故事 → 确认创作资料 → 写正文”组织功能，作品正文和创作资料默认只保存在你的电脑上；AI 凭据由运行环境统一管理。

当前版本：`1.1.0`。

默认采用“纸白石墨＋雾蓝”主题。正文顶部可折叠章节栏、打开 AI 助手或进入专注模式；Escape 退出专注。窄屏侧栏以抽屉显示，桌面折叠偏好保存在当前浏览器。配色与面板开关不影响稿件内容、导出或 AI 设置。

本地内测版正在实施，未发布进度与尚未通过的验收项见 [实施检查点](docs/LOCAL_BETA_PROGRESS.md)。作品菜单提供导入、设定、用量和备份入口；正文侧栏提供场景规划、章节历史和回收站。用户仅选择模型，Key 仍由运行环境管理。

## 安装桌面版

普通作者推荐使用 GitHub Releases 中的 Windows x64 安装包：

1. 下载名称类似 `墨台 Setup 1.1.0.exe` 的文件。
2. 运行安装向导并选择安装位置。
3. 从桌面快捷方式或开始菜单打开“墨台”。

安装包尚未签名。Windows SmartScreen 若显示“未知发布者”，请先确认文件来自本仓库，再选择“更多信息” → “仍要运行”。

程序和数据分开保存。作品与本地配置位于 `%APPDATA%\墨台\`，升级或卸载程序不会主动删除它们。首次启动仍会尝试迁移早期安装中的作品、封面和 AI 配置。

## 第一次使用

1. 点击作品名称区域，选择“新建作品”。
2. 填写作品名和一句灵感，点击“创建并开始”。
3. 在“AI 创作”中讨论故事、人物或核心冲突。
4. 点击右侧创作资料卡片的“让 AI 整理”，检查草案后选择要写入的部分。
5. 打开“创作资料”，继续编辑故事大纲、人物关系、世界观和关键事件时间线。
6. 打开“正文”，新建或选择章节后开始写作。正文会自动保存。

AI 生成的资料会先成为草案，只有点击“确认写入”后才会修改作品。已写入的草案支持立即撤销。

## AI 设置

点击左下角“设置”打开 AI 配置：

- 使用者只需从设置页选择运行环境已经开放的 DeepSeek 或 OpenAI 模型，页面不接收 API Key。
- 连接检测会从服务商官方模型列表中自动选择可用于长篇写作的模型，无需手动维护 Base URL、接口类型或模型名。
- 地址、接口类型和默认创作模型由墨台按服务商自动配置，设置页不再要求手动填写高级参数。
- 配置会持久保存在本机的 `.env.local`；应用每次打开都会检测 AI 连接。
- 未配置或连接失败时会明确提示“AI 不可用”，不会用预设内容代替真实模型回答。

API Key 仅保存在本机，不会提交到 GitHub。文本接口测试成功不代表图片接口也可用；图片生成能力仍由本地服务 API 保留，后续会在新版界面中重新接入。

## 长篇一致性工作流

正文侧栏每次生成都会由服务端重新读取当前作品，不采信浏览器传来的旧作品快照。服务端会组合设定库、作者已确认的 Canon 事实和最近章节记忆，生成后检查重复段落并调用模型做人物、事件、时间线和因果审校。硬冲突最多自动重写两次；仍有硬冲突时不能写入，界面会列出问题供作者补充指令。

作者接受一段正文后，章节和生成记录会在同一事务中保存。模型提取出的新事实不会自动成为设定，而是弹出事实提案，由作者逐条确认后才用于后续章节。这样可以先完成本地单人 MVP，未来接入账号与数据库时仍沿用 `ownerId`、数据库版本和服务端权威写入边界。

## 作品管理与导出

点击顶部作品名称可以：

- 切换或新建作品；
- 修改作品信息；
- 导出 Markdown、TXT、HTML、Word 或 PDF；
- 删除当前作品。

本地服务会继续创建自动快照并保留底层备份、封面和迁移能力。旧版工作台界面已经移除，不再提供单独入口。

## 本地开发

需要 Node.js 24 LTS 和 pnpm：

```powershell
pnpm install
pnpm start
```

浏览器访问 `http://127.0.0.1:5177`。

桌面窗口调试：

```powershell
pnpm run desktop
```

构建 Windows 安装包：

```powershell
pnpm run make:win
```

## 验证

基础检查：

```powershell
pnpm run check
```

新版浏览器关键流程：

```powershell
pnpm run test:e2e
```

测试覆盖新建作品、AI 对话、创作资料草案、富文本正文自动保存、对话记录和 900px 平板布局。

## 项目结构

```text
desktop/                 Electron 主进程和桌面数据迁移
e2e/                     新版工作台浏览器流程测试
public/index.html        新版工作台结构
public/studio.js         新版工作台交互
public/studio.css        新版工作台样式
src/                     领域规则与 JSON 存储层
test/                    Node 单元和接口测试
data/db.example.json     可提交的示例作品库
docs/                    架构、交接和协作文档
server.js                HTTP 服务、AI 编排、备份恢复和导出
```
