# 墨台小说创作平台

墨台是一个本地优先的中文小说创作工具。它可以管理作品和章节、整理世界观与人物、调用自选 AI 写作接口、生成带书名、类型标签、故事导语与作者署名的小说平台风格封面，并把作品导出为常用文档。

当前正式版本：`1.1.0`。作品正文、封面和 API Key 只保存在你的电脑；GitHub 只保存程序代码。后续版本目标见[产品路线图](docs/ROADMAP.md)。

开发前请先阅读 [工程交接文档](docs/HANDOFF.md) 和 [架构说明](docs/ARCHITECTURE.md)。每次版本更新都记录在 [更新日志](CHANGELOG.md)。

## 1. 安装桌面版

普通作者推荐使用 GitHub Releases 中的 Windows x64 安装包：

1. 打开仓库的 `Releases` 页面，下载名称类似 `墨台 Setup 1.1.0.exe` 的文件。
2. 双击安装包，在安装向导中选择程序安装位置；可以安装到 D 盘或其他位置。
3. 安装完成后，从桌面快捷方式或开始菜单打开“墨台”。它会以独立窗口运行，不会打开外部浏览器。
4. 首次启动时，程序会自动尝试导入旧工程中的作品、封面和 AI 配置。若没有旧数据，直接创建新作品即可。

安装包尚未签名。Windows SmartScreen 若显示“未知发布者”，请先确认文件来自本仓库，再选择“更多信息” -> “仍要运行”。

> 程序安装目录和数据目录不同：安装位置由你选择；作品、封面和 API 配置保存在 `%APPDATA%\墨台\`，升级或卸载程序不会主动删除它们。

## 2. 第一次写小说

1. 打开墨台后，在入口页点击“进入”。
2. 点击左侧“新作品”，填写书名、类型、目标字数、标签和一句话梗概。
3. 一句话梗概尽量写清主角身份、开局变化、核心能力、敌人、长期目标和冲突。例如：

   ```text
   普通青年魂穿成即将进入超神学院的战士，得到只能通过改变关键事件升级的系统；他必须在星际战争爆发前联合队友、开发力量，并阻止幕后势力提前开启虚空计划。
   ```

4. 点击“创建”，进入顶部“项目”页面，检查并补充梗概。
5. 点击“生成设定”，等待生成世界观、人物、势力、主线、分卷大纲和章节规划。
6. 进入“设定库”，从顶部的“从梗概到正文”路线开始。它会显示 5 个步骤和当前下一步；点击每一步右侧的按钮即可跳到相应页面。也可以点“检查下一步”，让墨台重新检查设定质量。
7. 如果检查结果显示红色问题，不需要自己猜该填哪里：点击问题后面的“补人物关系”“补章节规划”“检查梗概”或“补核心设定”，程序会直接打开对应页面并定位到可编辑区域。
8. 分别进入“人物”“世界观”“时间线”检查和补充结果。人物页可以直接用“人物卡”和“关系卡”编辑姓名、目标、秘密、成长弧和矛盾，关系图会同步刷新；高级文本格式仍支持“姓名：身份｜目标｜秘密/弱点｜成长弧”和“甲 -> 乙：关系｜当前状态｜矛盾”。
9. 回到“创作”，给第一章起标题；再打开“AI 助手”，输入本章要求后选择“按指令写”，或直接点击“续写”。

AI 每次生成都会重新读取作品梗概、设定库、人物关系、章节规划、当前章节和连续性提醒，减少上下文丢失和剧情跑偏。重新生成设定时，程序只以当前作品的标题、类型、标签和梗概判断题材；即使旧设定曾经填错，也会被新的结果覆盖，不会作为新作品的生成依据。

### 设定不完整时，具体怎么补

把“设定库”当作写作前的导航图，而不是需要一次性填写完的问卷。按下面顺序补，通常只要 10 至 20 分钟就能让 AI 有足够上下文：

1. **先补梗概**：至少写清“谁”在“什么开局”遇到“什么阻碍”，并说明他/她想达成什么目标。不要只写“这是一个爱情故事”。例如：`记忆被重置的星港赏金猎人劫走一名即将销毁的少女型仿生人；两人一边追查销毁名单，一边躲避企业舰队追捕。`
2. **再生成设定**：点击“生成设定”。生成结果显示“本地备用”并不表示失败，只表示没有调用付费模型；已识别的题材会生成可继续编辑的基础设定。陌生或复杂题材想要更细的内容，配置真实文本接口后再生成一次。
3. **给角色起真实姓名**：在“人物”页面至少保留 4 个有名字的人物。每个人至少填写身份、想要什么、害怕失去什么。例如：`沈砚川：星港赏金猎人｜找回失踪弟弟｜害怕再次害死同伴｜从独行者学会信任。`
4. **写清关系箭头**：关系不能只写“朋友”或“敌人”。用 `甲 -> 乙：关系｜当前状态｜矛盾`，例如：`沈砚川 -> 祁月：保护者/搭档｜互相试探｜祁月的记忆可能指向沈砚川的弟弟。` 至少补 3 条，关系图才会出现有意义的箭头。
5. **补章节推进**：在“时间线”至少保留 8 章。每章按“目标、冲突、结尾钩子”写一行，例如：`第3章｜逃离月港｜目标：带祁月离开销毁区｜冲突：旧搭档拦截｜结尾钩子：祁月叫出了失踪弟弟的名字。`
6. **最后才写正文**：打开“创作”，选择当前章节，先在 AI 助手写清本章目标，再点“按指令写”。正文写完后把真正发生的事件补回当前章纲和连续性提醒，下一章就不会脱线。

质量分数是“是否足够让 AI 持续写下去”的提醒，不是对作品好坏的评价。低分时优先修复红色问题；等人物、关系和 8 章以上的推进都补齐后，再追求世界观细节和伏笔密度。

## 3. 使用 AI 写作

### 配置文本接口

1. 点击顶部“接口”。
2. 在“文本写作”中选择服务商，填写 API Key、API 地址和模型名。
3. OpenAI Responses 使用 `Responses`；大多数兼容接口使用 `Chat`。
4. 点击“保存”，再点击“测试”。测试成功后即可在“AI 助手”页面创作。

常用地址示例：

```text
OpenAI: https://api.openai.com/v1
DeepSeek: https://api.deepseek.com
```

如果想要一次生成接近 2000 个汉字，可将输出上限设为约 `3200`，超时设为 `30000` 毫秒或更高。实际字数会受模型、提示词和服务商限制。

### AI 按钮怎么选

- `续写`：承接当前正文，直接推进本章剧情，并自动插入正文末尾。
- `按指令写`：按输入框中的具体要求写正文；有选中文本时替换选中内容，否则追加到末尾。
- `扩写`：补充选中段落的环境、动作、心理或对话。
- `润色`：优化选中段落的表达，不改变剧情事实。
- `大纲`、`灵感`：只在结果区给出建议，不自动改正文。

希望直接得到正文时，请在指令末尾写：

```text
只输出小说正文，不要分析、说明、列表或写作方案。
```

### 大胆程度

在“设定库”中使用滑动条调整大胆程度：

- `0-30`：稳妥，严格贴合已有设定。
- `31-70`：平衡，有新意但不改核心。
- `71-100`：大胆，增加冲突、反转和新奇设定。

大胆程度只影响创意强度，不会绕过内容安全边界，也不应该推翻作品核心世界观。

### 图片与封面接口

封面图片可在“接口”的“图片生成”区域单独配置。图片 API 地址通常填写服务根地址，例如 `https://api.openai.com/v1`，不要自行补上 `/images/generations`。模型需是账号有权限使用的图片模型，例如 `gpt-image-1`。

在“封面”页面，先在“项目”填写作者/笔名，再点击“生成封面”。墨台会让图片模型绘制背景画面，并在本地稳定叠加书名、类型与标签、故事导语、作者署名，形成小说平台常见的信息版封面，避免由模型生成错别字。你也可以点击“添加本地图片”，选择自己的 PNG、JPG 或 WebP 图片（单张不超过 25MB）；本地图片不会上传到 GitHub。

每次 AI 生成或添加本地封面，都会保存为该作品的一个封面版本。封面工坊下方和右侧“封面”快捷卡都能查看最近版本；点击缩略图即可把旧版本重新设为当前封面。完整备份会包含这些封面版本。

如果你后来修改了书名、作者/笔名、类型、标签或一句话梗概，进入“封面”的“封面信息排版”可调整色彩、书名位置、故事导语与四种叠加信息（书名、类型与标签、导语、作者）。上传一张已经排好文字的成品封面时，取消全部勾选后再“添加本地图片”，墨台会原样保留图片，不再添加重复水印。点击“应用信息排版”会保留背景图，仅新增一版文字排版封面；不满意时可从历史缩略图恢复旧版。

### 每章推荐写作顺序

1. 在“时间线”的“章节推进看板”确认当前章节处于草稿、写作中还是已完成；点击卡片可跳转章节，并在“当前章节计划”填写剧情目标、场景、出场人物、冲突与结尾钩子。
2. 在“创作”页填写章节标题；章节列表悬停会显示“改名”和“删除”，改名会定位到顶部标题框，删除会二次确认。正文为空时，用“AI 助手”输入本章目标，再点“按指令写”。已有正文时直接点“续写”。
3. 先阅读结果区或新增到正文末尾的内容，保留合适段落、手动改掉不符合角色口吻的部分。
4. 需要加戏时选中一段再点“扩写”；只想改善表达时选中一段再点“润色”。
5. 每写完一章，回到“时间线”补充已发生事件和伏笔状态，再新建下一章。这样下一次 AI 生成会拿到更准确的连续性上下文。

### 在正文中插入图片

1. 在“创作”页把光标放到希望出现图片的位置，点击正文工具栏的“图”。
2. 填写“图片说明”和“AI 画面方向”，点击“AI 生成并插入”。系统会读取当前章节、作品梗概、设定库、当前章纲和连续性提醒，生成横向剧情插图。
3. 或点击“添加本地图片”，选择自己的 PNG、JPG 或 WebP 图片。
4. 图片会以 `![图片说明](/data/covers/illustration-...)` 的形式插入正文；在“预览”中显示为插图。你可以像普通文字一样剪切、移动或删除这一整行。

章节插图和封面都会保存在本机，也会进入“导出完整备份”。Markdown 导出保留图片引用，HTML 和 Word 导出会显示图片；TXT 和 PDF 导出保留图片说明占位，适合以正文为主的阅读和备份。

右上角“壁纸”可为整个工作台选择背景。默认“自动匹配”会让晨光、深墨、夜航、暖夜分别使用不同的内置 AI 壁纸；也可以选中一张固定内置图、关闭壁纸、点击“添加图片”放入自己的 PNG/JPG/WebP，或填写画面方向后点击“生成作品壁纸”。打开某部小说时，生成会自动参考该作品的书名、梗概、世界观、人物与冲突来匹配气质，但壁纸不会画入书名或作者等文字，以免影响界面可读性。自定义壁纸保存到 `%APPDATA%\墨台\data\wallpapers\`，不会进入小说备份或 GitHub。

文本接口能测试成功，不代表图片接口一定可用。请分别检查图片 Key、模型权限和额度。

## 4. AI 出错时怎么办

墨台会给出中文原因和下一步提示：

- `未配置`：到“接口”填写并保存 API Key、地址和模型。
- `401`：Key 无效、过期或复制不完整，请重新创建并保存。
- `403`：账号没有该模型或接口权限，请换有权限的模型。
- `429`：额度不足、限流或并发过高，请充值、稍后再试或降低频率。
- `404`：地址或接口类型不匹配；通常只填服务根地址，再确认选择了 Responses 或 Chat。
- `超时/网络错误`：检查网络、代理和超时设置；代理示例为 `http://127.0.0.1:7890`。

启用“失败时使用本地备用”后，界面会明确标记“本地生成”。本地备用会按已识别题材生成可编辑的设定；例如都市失忆重逢会为主角、好友和知情人生成稳定的中文姓名、明确关系和12章推进表。同一标题与梗概重复生成会保持同一组姓名。它仍不能替代已配置的真实模型质量。

## 5. 导出、备份与恢复

### 导出单本作品

右上角选择格式后点击下载图标。支持：

- `Markdown`：继续编辑、交给 AI 或迁移到其他写作工具。
- `TXT`：通用纯文本备份。
- `HTML`：浏览器阅读或复制排版。
- `Word`：Word/WPS 可打开的 `.doc` 文件。
- `PDF`：阅读与分享。

### 完整备份

1. 打开顶部“项目”。
2. 在“备份与恢复”中点击“导出完整备份”。
3. 妥善保存下载的 `.motai-backup.json` 文件。

完整备份包含所有作品、章节、设定和本地封面，**不包含 API Key**。

墨台还会在首次保存以及之后每 12 小时自动创建一份本地快照，默认保留最近 7 份。自动快照仅保存在 `%APPDATA%\墨台\backups\`，不会上传 GitHub，也不能替代你自己下载并妥善保存的完整备份。

### 恢复备份

1. 打开顶部“项目”。
2. 点击“恢复备份”，选择此前导出的 `.motai-backup.json`。
3. 确认恢复。程序会先自动创建一份带时间戳的本地回退备份，再校验备份结构和图片类型/大小。
4. 恢复完成后，作品库和封面将切换为备份内容；现有 API 配置会保留，不必重新填写 Key。

恢复失败不会覆盖当前作品库。备份文件不要提交到 GitHub 或公开网盘。

## 6. 主题与界面

右上角“主题”按钮可选择：晨光、深墨、夜航、暖夜；旁边的“壁纸”可选择工作台背景。默认“自动匹配”会让主题与内置壁纸同步变化，也可固定某一张、自定义上传、用图片模型生成或关闭壁纸。首页右侧主视觉也会随主题同步切换；点击“AI 生成主页图”可替换为自己的图片，并可用“恢复主题图”回到内置版本。墨台会记住选择；深色主题下的弹窗、输入框、菜单、导出面板和错误提示均应跟随主题。

每次打开墨台都会先显示首页。点击“进入”后，程序会自动恢复上次使用的作品、章节、正文/预览模式、主题、壁纸、导出格式和右侧快捷栏偏好。桌面版会将这些无敏感偏好保存在 `%APPDATA%\墨台\ui-preferences.json`，因此即使每次启动使用不同的本机端口也不会重置；其中不包含正文、设定库、图片二进制或 API Key。若你删除了上次打开的作品，墨台会安全回退到现有作品或空工作台。

右侧只保留统计和常用快捷工具；完整的作品信息、AI、设定库、人物、世界观、时间线、封面和接口都在顶部导航中展开。

## 7. 源码开发

网页模式只用于开发调试。需要 Node.js 24 LTS 和 pnpm：

```powershell
pnpm install
pnpm start
```

浏览器访问 `http://127.0.0.1:5177`。桌面窗口调试：

```powershell
pnpm run desktop
```

构建 Windows 安装包：

```powershell
pnpm run make:win
```

安装包输出到 `out\electron-builder\`，该目录不会提交到 GitHub。
